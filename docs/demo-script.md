# Three-minute demo plan

0:00–0:20 — Problem and target. Small professional offices need a clear bundle without a sales visit. Overall synthetic baseline: 7.36% activation, 17.6 days to activate.

0:20–0:55 — Discover. Five-person clinic, one tier-2 location, fibre available, internet/email/security, ₹5,000 budget, 12-month ceiling. State that the clinic already uses home broadband and personal Gmail. Show the current-setup comparison and a language switch. Use the new AI chat after key configuration and live testing; do not present mocked responses as live GenAI.

0:55–1:20 — Quote. ₹2,619/month before taxes: broadband ₹1,499, five email seats ₹625, five security licences ₹495. Show an add-on changing the quote. Explain setup, per-product contracts and honest activation estimates.

1:20–2:10 — KYC. Consent before processing. Show a valid fictional specimen, local extraction, registry/name/date checks and masked results. Then show a separate failing specimen or expired document and the correction message. Do not describe role checks as real identity verification.

2:10–2:35 — Order. Confirm demo quote, create simulated order and show tracker. Advance a fulfilment event using the clearly labelled demo control. Installation is not instantaneous.

2:35–3:00 — Evidence and boundary. Professional-office pilot rationale; measured baselines versus proposed targets; local processing and deletion choices. Finish with repo/architecture/privacy links and distinguish mocked integrations.

Do not record the final video until GenAI is connected and required flows pass. Keep video ≤180 seconds, with readable UI and no secrets.
